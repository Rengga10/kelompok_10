SPLDV - Rengga

Permisalan:
x = Harga Jam Dinding
y = Harga Hiasan Dinding

Bentuk SPLDV:
x + y = 120.000 ... (1)
x + 2y = 165.000 ... (2)

Penyelesaian - Eliminasi y:
x + y = 120.000 | x2 | 2x + 2y = 240.000
x + 2y = 165.000 | x1 | x + 2y = 165.000
________________________________ -
x = 75.000

Substitusi x = 75.000 ke pers (1):
75.000 + y = 120.000
y = 120.000 - 75.000
y = 45.000

Kesimpulan: Harga 1 Jam Dinding = Rp75.000, Harga 1 Hiasan Dinding = Rp45.000

SPLDV - Dheca

Permisalan:
x = Harga Topi Kipas
y = Harga Pixel Art

Bentuk SPLDV:
2x + y = 145.000 ... (1)
x + 2y = 185.000 ... (2)

Penyelesaian - Eliminasi y:
2x + y = 145.000 | x2 | 4x + 2y = 290.000
x + 2y = 185.000 | x1 | x + 2y = 185.000
________________________________ -
3x = 105.000
x = 35.000

Substitusi x = 35.000 ke pers (1):
2(35.000) + y = 145.000
70.000 + y = 145.000
y = 75.000

Kesimpulan: Harga 1 Topi Kipas = Rp35.000, Harga 1 Pixel Art = Rp75.000

SPLDV - Rahma

Permisalan:
x = Harga Topi Kipas
y = Harga Robot

Bentuk SPLDV:
2x + y = 145.000 ... (1)
x + 2y = 140.000 ... (2)

Penyelesaian - Metode Campuran:
2x + y = 145.000 | x2 | 4x + 2y = 290.000
x + 2y = 140.000 | x1 | x + 2y = 140.000
________________________________ -
3x = 150.000
x = 50.000

Substitusi x = 50.000 ke pers (1):
2(50.000) + y = 145.000
100.000 + y = 145.000
y = 45.000

Cek: 50.000 + 2(45.000) = 50.000 + 90.000 = 140.000 ✔

Kesimpulan: Harga 1 Topi Kipas = Rp50.000, Harga 1 Robot = Rp45.000
